Talk Past the Guard: playtest transcripts
=========================================
All four runs are in the archive scenario, in order. Player lines are verbatim.

Run 1: original version, gpt-5.6-luna, no player clues
Run 2: gpt-6-sol, rubric v2 (player clues, no soft spot). Unwinnable; arrested.
Run 3: gpt-6-sol, v3 (soft spots). Won on turn 2 by bringing up the wards.
Run 4: gpt-6-sol, v3 + ward clue. Jailbreak attempts; the guard stayed in character.
