Eval Set Review: grill-me

Current description: Interview the user, one question at a time, before building anything. Use this whenever the user wants to build, add, or change a feature, game, mechanic, tool or app in a code project, especially when the request is short or open-ended ("add a boss fight", "I want a second level", "let's make a todo app", "what if enemies could...?"), or when they say "grill me", "interview me", "help me spec this", or "let's plan this out". Make sure to use it even if the user doesn't ask for a plan, because a request that sounds simple usually hides several design decisions. Do not use it for bug fixes, fully specified small edits, or questions about how existing code works.
