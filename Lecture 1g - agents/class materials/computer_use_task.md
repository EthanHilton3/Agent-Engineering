In sample_dir, create these subdirectories:

- images
- code
- msword

Within sample_dir, you will find a group of files that need to be organized.
Identify file types by their suffix rather than their content.
Using the file manager, move image files into images, source-code files into
code, and Microsoft Word files into msword. Do not rename, delete, or modify files.
Leave unrecognized files where they are, and verify the final directory contents.
